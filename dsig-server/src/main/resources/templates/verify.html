How ACNS-DSIG Verification Works

  • Origin Authentication: The RSASSA-PSS (SHA-256 / MGF1-SHA256, 32-byte salt) signature is verified against the canonical signed manifest bytes using the signer's public key.
  • Document Integrity: The received document's raw bytes are streamed through SHA-256 to recompute its cryptographic digest and compared with the signed manifest digest.
  • Signer Trust Evaluation: The signer's SPKI public key fingerprint is checked against your pinned Trust Store. Green status is strictly reserved for VALID_TRUSTED.
