How signing works:
  1. Your document is streamed through SHA-256 to produce a 256-bit digest.
  2. A manifest containing the hash, size, algorithm, key ID, timestamp and nonce is constructed.
  3. The manifest bytes are signed with your private RSA-3072 key using RSASSA-PSS.
  4. A detached .dsig.json envelope containing the manifest and signature is produced — the original document is not modified.
