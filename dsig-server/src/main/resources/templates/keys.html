                    Security Architecture Notes:
                    
    
                        
  • Private key bytes are encrypted at rest using PKCS#8 / PBES2 / AES-256 and never stored in the database or returned to the browser.
    • 
                        
  • Share your fingerprint via a trusted side-channel (email, phone) so verifiers can pin your key identity.
    • 
                        
  • Retire a key when you stop using it. Old signatures remain mathematically verifiable but their trust status is evaluated separately by verifiers.
