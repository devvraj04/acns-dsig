# Benchmarks & Performance Analysis

**Owners:** Devraj Sundrani & Tanmay Vishwakarma

This directory stores benchmark test suites, profiling data, and throughput charts comparing:
1. Streaming SHA-256 vs. in-memory buffer overhead for 1 KB, 1 MB, and 25 MB documents.
2. RSA-3072 signing and verification latency.
3. Memory consumption under concurrent verification requests.
